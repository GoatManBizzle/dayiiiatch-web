# DAYIIIatch Space Friendly Layout Standard

Portal, admin, and dashboard pages should use available workspace width before stacking content into narrow columns.

- Avoid huge dead zones, decorative empty panels, and one-column content squeeze.
- Use full-width headers and category/status strips when they help orientation.
- Put summary/support content in compact side panels, not oversized empty columns.
- Let repeated operational cards become responsive grids before forcing list layouts.
- Keep card actions grouped consistently at the bottom or directly beside their content.
- Use `min-w-0`, wrapping metadata, and stacked mobile grids to prevent horizontal overflow.
